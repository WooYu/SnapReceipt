# Agent Rules

## Build / Compile Policy
- Default: do not run compile/build/test/lint commands automatically.
- Only run `gradlew` (or any compile/build/test/lint command) after explicit user instruction in the current conversation.

## Cursor Cloud specific instructions

### Project overview
SnapReceipt is a multi-module Android app (Kotlin, Gradle KTS, Hilt DI). Modules: `app`, `core-base`, `core-foundation`, `core-data`, `core-domain`, plus `build-logic/convention` for custom Gradle plugins.

### Environment
- **Android SDK** is installed at `/opt/android-sdk` with platform 36 and build-tools 36.0.0.
- `ANDROID_HOME` is set in `~/.bashrc`. The `local.properties` file with `sdk.dir` is generated by the update script.
- **JDK 21** (system-installed) is used; the project targets JVM 17 which is compatible.

### Known issues
- **`gradlew` wrapper script bug:** The `DEFAULT_JVM_OPTS` in `gradlew` contains embedded double-quotes that cause `java.lang.ClassNotFoundException: "-Xmx64m"`. Workaround: invoke Gradle directly via `java -Xmx64m -Xms64m -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain <task>`.
- **Pre-existing test failure:** `core-data:testDebugUnitTest` fails with `InvalidTestClassError` on `ReceiptRemoteRepositoryImplTest.list_failure_throwsApiException()` because `runBlocking` returns `Unit` instead of `void`. This is a codebase bug, not an environment issue.
- **Pre-existing lint errors:** `core-foundation:lintDebug` fails (33 errors) due to `java.time` API usage (`NewApi`) without desugaring in `core-foundation`. The `app` module has desugaring enabled but `core-foundation` does not.

### Common commands
| Action | Command |
|---|---|
| Debug build | `java -Xmx64m -Xms64m -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain assembleDebug --no-daemon` |
| Unit tests | `java -Xmx64m -Xms64m -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain testDebugUnitTest --no-daemon` |
| Lint | `java -Xmx64m -Xms64m -classpath gradle/wrapper/gradle-wrapper.jar org.gradle.wrapper.GradleWrapperMain lintDebug --no-daemon` |

### Notes
- This is a mobile-only project; there is no backend or web server to start. The "hello world" for environment verification is a successful `assembleDebug` producing a debug APK.
- The app depends on a remote backend API (not in this repo) for runtime data operations.
- No Android emulator is available in Cloud Agent VMs, so running the APK on-device is not possible. Build verification is the primary test.
